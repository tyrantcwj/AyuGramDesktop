# iTycGram

iTycGram 是一份 Telegram Desktop 分支，界面设置为简体中文。

源码基于 Telegram Desktop 与其下游修改，版权仍归原作者所有，授权协议是 GPL-3.0。内部目录名 `ayu/` 和翻译键前缀 `ayu_` 保持不变，这样还能继续使用现有的简体中文语言包；加载语言包时会把其中的旧产品名替换成 iTycGram。

## 名称

- 程序名：`iTycGram.exe`
- 关于页标题：`iTycGram 桌面版`
- Windows 安装包标识已换成新的 AppId，避免和原来的客户端装在一起时互相覆盖

## 编译

Windows 编译步骤仍沿用上游文档：[docs/building-win.md](docs/building-win.md)。仓库地址是 https://github.com/tyrantcwj/iTycGram 。
